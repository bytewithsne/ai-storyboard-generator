# 🎬 AI Video Storyboard Generator

An AI-powered web application that turns a simple video idea into a structured storyboard with detailed prompts for AI video generation.

## 🚀 Features

- Generate multi-scene video storyboards
- Choose from different visual styles
- Define the number of scenes
- Generate detailed visual descriptions
- Generate AI-ready video prompts
- Simple and easy-to-use interface

## 🛠️ Tech Stack

- Python
- Streamlit
- OpenAI API

## 💡 How It Works

1. Enter a video idea.
2. Select the number of scenes.
3. Select a visual style.
4. The AI generates a structured storyboard.
5. Each scene includes camera direction, duration, visual description, and a video-generation prompt.

## 🎯 Purpose

This project explores how LLMs can be used to convert high-level creative ideas into structured inputs for AI video generation workflows.
